# Learn GenAI

A hands-on learning project focused on building practical AI-powered applications with Node.js, LangChain, and Mistral AI. This repository demonstrates how to connect large language models to real user interactions, manage prompt context, and build simple chat experiences from scratch.

## Project Overview

This project is designed to showcase foundational Generative AI skills in a way that is easy for recruiters and technical reviewers to understand. It highlights the ability to:

- build AI-driven chat applications
- work with prompt templates and conversational history
- integrate third-party LLM APIs securely
- structure projects in a clean, beginner-friendly way

## What I Built

- Day 01: A command-line chat app that takes user input and responds using an LLM.
- Day 02: An extended version that explores prompt engineering and message history for more context-aware interactions.
- Shared configuration setup for environment-based API key management.

## Tech Stack

- JavaScript / Node.js
- ES Modules
- LangChain
- Mistral AI
- dotenv

## Why This Matters for Recruiters

This project reflects practical experience in modern AI development, including:

- real-world LLM integration
- prompt design and conversational flow
- secure handling of API credentials
- rapid prototyping and iterative learning

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a `.env` file in the project root using `.env.example` as a reference.
3. Run the examples:
   ```bash
   node Day01/chat.js
   node Day02/chat.js
   ```
